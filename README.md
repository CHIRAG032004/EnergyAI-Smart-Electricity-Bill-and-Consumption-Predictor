This report documents the problem definition, requirements, methodology, architecture, Python concepts, implementation, testing approach, results, team contributions, challenges, and learning outcomes of EnergyAI, a Smart Electricity Bill and Consumption Predictor.
EnergyAI reads a household’s monthly or daily electricity readings from a CSV file, forecasts units and bill for the next six months with an 80% confidence band, flags abnormal spike and drop days, scores the usage pattern as a health score out of 100, and lets the user test appliance-level savings in rupees and CO₂. The backend uses only the Python standard library with an SQLite database, so the whole system runs offline on a laptop. On the 30-month demo bill file the forecast model reached a mean absolute percentage error of 3.4%, and on the seeded demo data it flagged all three planted anomalies.
